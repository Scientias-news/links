# Scientias – link in bio

Mobiele linkpagina voor de Instagram-bio van Scientias.nl: https://scientias-news.github.io/links/

- `index.html`: de pagina (laadt `posts.json`).
- `posts.json` en `img/`: de nieuwste posts, bijgewerkt door de Scientias-socialbot.
- `linkpagina.py toevoegen ...`: zet een post bovenaan (max. 60).
